
# BeReal Memories 📸
Export your BeReal memories with a simple UI by parsing the BeReal data export package. Built with [Astro](https://astro.build/) & [Tailwind](https://tailwindcss.com/).

![Screenshot](https://r2.vasc.dev/images/1Mtq6.png)

## Motivation
I wanted to have my BeReals in my own gallery, but the app doesn't allow anyone to export all their BeReals with one click. So I created this tool to make it easy to export my BeReals from time to time. It also embeds the BeReal date into the image's EXIF data so it's placed correctly next to other photos in your photo timeline.

## Features
- Export one or more days 📅
- Support for multiple BeReals 🤳
- BeReal date embedded in EXIF data ℹ️
- Shift multi-select ⌨️
